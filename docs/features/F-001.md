# M0 vertical slice — boss fight + menu đầy đủ

## Mô tả
Gameplay hoàn chỉnh, chơi thật (không phải mockup):

- **Player = Dark Queen (boss)** trong arena side-view. Move A/D hoặc ←/→, 3 skill:
  - **Slash** (J/X): cận chiến, dmg cao nhẹ, knockback nhỏ.
  - **Shadow bolt** (K/C): projectile, cooldown ngắn.
  - **Nova** (L/V): AoE quanh queen, dmg lớn, cooldown dài.
- **Enemy = Hero AI** (1 con, đúng yêu cầu "tạm thời chỉ có 1 boss"): tiến lại,
  telegraph rồi chém; chết thì **hồi sinh mạnh hơn** (HP/dmg/speed tăng theo round).
  Giết hero đủ 5 lần → **Victory**; Queen chết → **Defeat**.
- **Phase 2** (Queen < 40% HP): bolt bắn đôi, nova to hơn.
- **Menu game đầy đủ** như 1 game thực thụ: Main menu (New Game / Settings /
  Credits / Quit), Settings (volume master/music/sfx, fullscreen, vsync — lưu
  `user://settings.cfg`), Pause (Esc), Victory/Defeat screen kèm stats,
  Credits (ghi nguồn asset + license).
- Asset thật từ nguồn CC0/CC-BY (OpenGameArt, Kenney, Google Fonts) — không còn
  placeholder hình học. Danh sách nguồn ghi trong `assets/CREDITS.md`.
- **BỎ QUA** (theo yêu cầu): hội thoại/story kiểu Mortholme (dồn cho M2).
